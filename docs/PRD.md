# Product Requirements Document (PRD)

## 1. 문서 정보
- 프로젝트명: AI 투자 자동화 시스템 (웹 구독형)
- 문서 버전: v1.0 (MVP 기준)
- 작성일: 2026-02-13
- 대상: Product, Engineering, Quant, Design, Ops, Compliance

## 2. 제품 개요
웹 로그인 기반의 구독형 AI 투자 자동화 서비스다. 사용자는 거래소 API를 연동해 자동매매를 실행하고, 실시간 대시보드에서 수익률과 리스크를 추적한다. 제품 목표는 단기 고수익만이 아니라 장기 생존 가능한 위험조정수익률의 극대화다.

## 3. 목표와 비목표
### 3.1 목표
1. 사용자가 10분 내 계정 생성, 결제, API 연동, 전략 활성화까지 완료할 수 있다.
2. 실시간 대시보드 지연을 3초 이내로 유지한다.
3. 자동매매 운영 중 리스크 한도(MDD, 일손실, 포지션 한도)를 강제한다.
4. MVP 출시 후 90일 내 유료 전환율 8% 이상을 달성한다.

### 3.2 비목표 (MVP 범위 외)
1. 주식/선물/옵션 멀티에셋 지원
2. 사용자 임의 전략 코드 업로드
3. 소셜 트레이딩/카피트레이딩 마켓플레이스

## 4. 사용자 페르소나
1. 바쁜 직장인 투자자
- 니즈: 24시간 모니터링 없이 자동 운용
- 성공기준: 손실 통제가 되는 자동매매

2. 데이터 기반 고급 사용자
- 니즈: 전략별 성과 비교, 리스크 지표 확인
- 성공기준: 대시보드 투명성과 지표 신뢰성

## 5. 가치 제안
1. 자동화: 신호 생성, 주문 실행, 리밸런싱, 경보까지 자동 처리
2. 투명성: 수익률뿐 아니라 MDD, Sharpe, 변동성 등 리스크 동시 공개
3. 통제: 비상 정지, 일손실 제한, 노출 한도로 급변장 방어

## 6. 핵심 KPI
### 6.1 투자 성과
- Net Return (월/분기)
- Sharpe Ratio, Sortino Ratio
- Max Drawdown (MDD)
- Win Rate, Profit Factor

### 6.2 제품/비즈니스
- 온보딩 완료율
- Free -> Paid 전환율
- 구독 유지율(30/90일)
- 월 구독 매출(MRR), Churn

### 6.3 운영 품질
- 주문 실패율
- 장애 복구 시간(MTTR)
- 실시간 데이터 지연 p95

## 7. 사용자 여정
1. 회원가입/로그인
2. 요금제 선택 및 결제
3. 거래소 API 키 등록 및 검증
4. 전략 선택(보수/중립/공격) 및 리스크 설정
5. 자동매매 시작
6. 실시간 대시보드 모니터링
7. 리포트 확인 및 구독 갱신

## 8. 기능 요구사항
### FR-01 인증/권한
- 이메일/소셜 로그인, 2FA, 세션 관리
- 관리자/일반 사용자 권한 분리

수용 기준:
1. 2FA 미설정 계정은 출금/고위험 설정 변경 불가
2. 비정상 로그인 시도 감지 시 사용자 알림 발송

### FR-02 구독/결제
- 월/연 결제, 플랜 업/다운그레이드, 자동갱신, 영수증
- 결제 실패 재시도 및 결제수단 변경

수용 기준:
1. 결제 성공 즉시 플랜 권한 반영(1분 이내)
2. 해지 예약 시 만료일까지 기능 사용 가능

### FR-03 거래소 연동
- API 키 암호화 저장, 권한 검증(조회/거래)
- 실거래/모의투자 모드 분리

수용 기준:
1. 키 검증 실패 시 원인 코드를 사용자에게 명시
2. 모의투자와 실거래 잔고/주문 데이터 완전 분리

### FR-04 AI 신호 및 자동주문
- 신호 생성 주기 설정
- 포지션 사이징, 진입/청산, 리밸런싱 자동화

수용 기준:
1. 주문 전 리스크 룰 통과 필수
2. 실패 주문은 정책에 따라 재시도 후 경보 발송

### FR-05 리스크 엔진
- 일손실 제한, 포지션 한도, 변동성 타깃, Kill Switch

수용 기준:
1. 일손실 한도 초과 시 신규 진입 차단
2. 비상 정지 시 모든 전략 상태가 `PAUSED`로 전환

### FR-06 실시간 대시보드
- 잔고, PnL, 전략 성과, 주문 내역, 리스크 알림
- WebSocket 기반 실시간 업데이트

수용 기준:
1. 데이터 지연 p95 3초 이내
2. 새 체결 이벤트가 UI에 5초 이내 반영

### FR-07 알림/리포트
- 체결/손익/리스크 이상 알림 (이메일/푸시/메신저)
- 일간/주간 성과 리포트 자동 발송

수용 기준:
1. 심각도 `HIGH` 경보는 1분 내 전달
2. 리포트에 비용(수수료/슬리피지) 포함

## 9. 비기능 요구사항
1. 보안: API 키 KMS 암호화, 전송 TLS 1.2+, 감사로그 보관 1년+
2. 성능: API p95 < 300ms (읽기), 주문 경로 p95 < 800ms
3. 가용성: 핵심 주문 서비스 월 가용성 99.9%
4. 확장성: 동시 접속자 10,000명까지 수평 확장
5. 감사가능성: 모든 주문 의사결정 근거(신호/룰) 추적 가능

## 10. 규제/법무 요구사항
1. 수익 보장 표현 금지, 투자 원금 손실 가능성 명시
2. 서비스 대상 지역별 규제 검토 및 접근 제한 정책 수립
3. 개인정보 처리방침/이용약관/면책조항 필수

## 11. 출시 전략
### 단계 1: 알파 (내부)
- 모의투자 전용
- 전략 1종, 거래소 1곳

### 단계 2: 베타 (초대 사용자)
- 실거래 소액 허용
- 리스크 엔진 및 경보 고도화

### 단계 3: GA (정식 출시)
- 플랜 3종
- 자동 리포트/결제/고객지원 체계 운영

## 12. 성공/실패 기준
### 성공 기준
1. 90일 이내 유료 사용자 300명
2. 90일 누적 MDD 목표 범위 준수
3. 주문 실패율 < 0.5%

### 실패 기준
1. 잦은 체결 불일치로 신뢰도 하락
2. 리스크 룰 미작동으로 대규모 손실 발생
3. 구독 해지율 급등(월 12% 초과)
